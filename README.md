# ScamBandhKaro

Your Digital Shield Against Online Scams

ScamBandhKaro is an AI-powered cyber safety platform that helps users detect, analyze, and report online scams in real time.

The platform provides intelligent scam detection tools, community reporting, live alerts, and educational resources to protect users from phishing attacks, fake job scams, UPI frauds, KYC scams, investment scams, and other cyber threats.

Live Website: https://scambandhkaro.online

---

## Features

### AI Scam Detection
Analyze suspicious:
- Messages
- URLs
- Emails
- Phone Numbers

The AI engine detects scam patterns, phishing indicators, urgency triggers, impersonation attempts, and malicious links.

## Protection Tools

### Message Scanner
Analyze SMS, emails, WhatsApp messages, and chats for scam language patterns.

### Link Analyzer
Check suspicious URLs for:
- Phishing attempts
- Fake domains
- Brand impersonation
- Unsafe redirects

### Phone Checker
Detect scam phone numbers and risky area codes.

### Email Verifier
Identify:
- Fake email domains
- Disposable emails
- Typosquatting attacks

## Installation

### Clone Repository

```bash
git clone https://github.com/your-username/scambandhkaro.git
cd scambandhkaro
```

---

### Create Virtual Environment

```bash
python -m venv .venv
```

Activate environment:

#### Mac/Linux

```bash
source .venv/bin/activate
```

#### Windows

```bash
.venv\Scripts\activate
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Project

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
